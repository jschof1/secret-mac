# Reporting a security issue

Do not include real credentials, env files or credential backups in an issue, screenshot or pull request. Use dummy values when reporting a bug.

For a vulnerability, use [GitHub's private vulnerability reporting](https://github.com/jschof1/secret-mac/security/advisories/new).

Read [Local data](docs/data.md) for the app's storage and clipboard boundaries. Secret edits plaintext local env files. It is not an encrypted password manager.

Secret

A small native Mac app for your envs.

Install

Drag Secret into Applications, then open it from Applications. Requires macOS 14 or later. Works on Apple Silicon and Intel Macs.

First launch

This release is unsigned by Apple and is not notarised. After attempting to open Secret, macOS may require approval in System Settings → Privacy & Security → Open Anyway. Approve only a copy downloaded from the official GitHub release.

Use

Search an env name. Use the copy button to copy its value. Press ⌘N to add an env. Use a row’s menu to edit or reveal it.

Secret uses ~/.env. The file is created when you save your first env. Existing entries stay in place. Values and backups are plaintext, stored locally with private permissions. Secret does not sync or upload them.
